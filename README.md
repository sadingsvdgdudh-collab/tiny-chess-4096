A 4 KB pure-Python chess engine: 0x88 move generation, negamax alpha-beta with
MVV-LVA ordering, tapered piece-square evaluation and a deterministic node budget.

## Run it

```sh
MAKEFUN_ENV_URL=... python3 main.py
```
